# DungeonX

DungeonX is a console-based RPG developed in C++ as an
Object-Oriented Programming practice project.

## Objective

The goal of this project is to build a small dungeon
adventure while applying core C++ OOP concepts in a
practical environment.

## Planned Concepts

- Encapsulation
- Inheritance
- Abstraction
- Abstract Classes
- Virtual Functions
- Runtime Polymorphism
- Function Overloading
- Friend Functions
- Composition
- STL Containers
- Exception Handling
